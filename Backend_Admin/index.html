線路狀態控制

在「線路資料管理」列表新增線路狀態（運作／維護）切換功能，可單條調整，也可一次調整全部線路。本文件供 UI 設計與前端確認畫面與行為。

User Story

身為營運人員，我想要快速切換單一或全部線路的運作／維護狀態，以便在維護期間阻止玩家進入，並於完成後恢復服務。

01

功能概述與流程

每條線路有兩種狀態：運作、維護。切換方式有兩種，都必須經過確認視窗才會生效。

狀態列舉

狀態開關的外觀與文字，依線框整理。

#狀態外觀說明
1運作圓鈕在左、文字「運作」在右；文字藍色，外框灰色預設狀態，線路正常提供服務。
2維護文字「維護」在左、圓鈕在右；文字與外框紅色線路維護中：玩家無法進入，切換當下遊戲中的玩家會被中斷提示擋住，無法繼續遊戲（見 03.3）。

新增功能

#功能位置說明
A單一線路調整列表「狀態」欄位的開關只改變該列線路的狀態
B全部線路調整頁面右上「線路狀態」一次將所有線路設為同一狀態

操作流程

兩種調整方式都是「點擊 → 確認視窗 → 取消／確認」三步驟。以下用線框逐步說明。

A單一線路調整（例：將 aws062 由運作切為維護）
1
點擊該列的狀態開關
在列表「狀態」欄點擊 aws062 的開關。點擊不會立即生效，開關維持運作。
2
跳出「更換狀態確認」視窗
內文帶入線路名稱與目標狀態：你即將把 aws062 的狀態設定為 維護。
  • 視窗開啟期間，列表上的開關維持原狀態，不預先切換。
  • 按「取消」或點擊視窗外部可關閉該視窗。
3
選擇取消或確認
取消
  • 關閉視窗。
  • aws062 維持運作，沒有任何變更。
確認
  • 關閉視窗，aws062 的開關更新為維護。
  • 不顯示任何成功／失敗提示，開關狀態即為結果。
  • 玩家無法再進入 aws062；正在遊戲中的玩家會立即被中斷提示擋住，無法繼續遊戲（見 03.3）。
B全部線路調整（例：全部維護）
1
點擊「全部維護」
在頁面右上「線路狀態」點擊「全部維護」（全部運作同理）。點擊不會立即生效。
2
跳出「更換狀態確認」視窗
與單一線路共用同一個視窗，內文主詞改為「全部線路」：你即將把 全部線路 的狀態設定為 維護。
3
選擇取消或確認
取消
  • 關閉視窗。
  • 所有線路維持原狀態，沒有任何變更。
確認
  • 關閉視窗，所有線路設為維護，不受目前分頁、每頁筆數影響（例：共 79 條即 79 條）。
  • 已經是維護的線路不受影響；重複操作也不會出錯。
  • 不顯示任何成功／失敗提示。
  • 所有線路上遊戲中的玩家都會被中斷提示擋住，無法繼續遊戲（見 03.3）。
  • 反向操作「全部運作」會把所有維護中的線路恢復為運作，包含先前個別設為維護的線路。
02

畫面拆解

先看參考線框，再逐一拆解每個區塊顯示什麼內容、有哪些狀態。圖上黃色編號對應下方表格。

02.1預設畫面

線路資料管理列表。新增右上「線路狀態」按鈕組，以及列表最右側「狀態」欄位。

#欄位狀態說明
1線路狀態-按鈕組標題，純文字，不可點擊。
2全部運作-點擊後跳出確認視窗（見 02.3），確認後將全部線路設為運作。文字為藍色，與運作狀態色一致。
3全部維護-點擊後跳出確認視窗（見 02.3），確認後將全部線路設為維護。文字為紅色，與維護狀態色一致。
4狀態（欄位標題）-新增欄位，位於「操作」右側、列表最後一欄。
5狀態開關運作線路正常運作中。點擊後跳出確認視窗（見 02.2），確認後切為維護。
6狀態開關維護線路維護中。點擊後跳出確認視窗（見 02.2），確認後切為運作。
02.2單一線路調整・確認視窗

點擊任一列的狀態開關時出現。視窗文字依「目標狀態」顯示運作或維護。

#欄位狀態說明
1標題-固定文字「更換狀態確認」。
2內文-「你即將把[線路名稱]的狀態設定為〔目標狀態〕」。[線路名稱] 帶入被點擊那一列的線路名稱並加粗，例：你即將把 aws081 的狀態設定為 運作。
3目標狀態運作
維護		顯示切換後的狀態，與目前狀態相反。字級放大加粗，運作為藍色、維護為紅色，與狀態開關顏色一致。
4取消-關閉視窗，該線路狀態不變。
5確認-送出變更並關閉視窗，該列開關更新為目標狀態。切為維護時，該線路上遊戲中的玩家會被中斷提示擋住，無法繼續遊戲（見 03.3）。
02.3全部線路調整・確認視窗

點擊「全部運作」或「全部維護」時出現。與 02.2 共用同一個視窗，僅內文主詞改為「全部線路」。

#欄位狀態說明
1標題-固定文字「更換狀態確認」，與 02.2 相同。
2內文-固定文字「你即將把全部線路的狀態設定為〔目標狀態〕」，「全部線路」加粗。
3目標狀態運作
維護		點「全部運作」顯示藍色運作；點「全部維護」顯示紅色維護。
4取消-關閉視窗，所有線路狀態不變。
5確認-將所有線路設為目標狀態（不限目前分頁），關閉視窗，列表開關同步更新。已是目標狀態的線路不受影響。全部維護時，所有遊戲中的玩家都會被中斷提示擋住，無法繼續遊戲（見 03.3）。
03

遊戲端維護提示

V2 新增

線路設為維護後，玩家在遊戲端看到的提示。此畫面由遊戲端顯示，不屬於後台介面。

03.1觸發時機與流程V2 新增

玩家在兩種情境下會看到遊戲端提示；兩種提示按下「OK」後都回到遊戲載入畫面重新進入。

#情境結果
A玩家嘗試進入維護中線路的遊戲無法進入，顯示維護提示（見 03.2）。
B線路切為維護時，玩家正在遊戲中遊戲畫面被中斷提示擋住，無法繼續遊戲（見 03.3）。
-按下任一提示的「OK」回到遊戲載入畫面重新進入。線路仍在維護中時，再次顯示維護提示；玩家重複按 OK 會一直重複此循環，直到線路恢復運作。
03.2維護提示視窗V2 新增

遊戲端的系統提示視窗，顯示維護訊息與一個「OK」按鈕。

#欄位狀態說明
1標題-顯示 System_Title（文字見 04）。
2訊息-顯示 Error_Code_24（文字見 04），代表該線路維護中。
3OK-回到遊戲載入畫面重新進入。線路仍在維護中時，會再次看到本提示（見 03.1 流程）。

提示文字的多語系對照見 04 文案對照・遊戲端文案。

03.3中斷提示視窗V2 新增

線路切為維護當下，正在遊戲中的玩家看到的提示。視窗覆蓋遊戲畫面，玩家無法繼續操作。

#欄位狀態說明
1標題-顯示 System_Title（文字見 04），與 03.2 相同。
2訊息-顯示 Error_Disconnect（文字見 04）。
3OK-回到遊戲載入畫面重新進入。線路仍在維護中時，接著顯示 03.2 維護提示。
